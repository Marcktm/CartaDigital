# Requerimientos No Funcionales (RNF)

1. **RNF01 - Usabilidad**
   La interfaz debe ser intuitiva y fácil de navegar, tanto para clientes como para administradores.
2. **RNF02 - Rendimiento aceptable**
   Las operaciones comunes (ver menú, hacer pedido, actualizar stock) deben ejecutarse en menos de 2 segundos.
3. **RNF03 - Portabilidad**
   La aplicación debe estar desarrollada en Flutter para permitir su ejecución tanto en dispositivos Android como iOS.
4. **RNF04 - Seguridad básica**
   Las contraseñas deben almacenarse de forma segura (por ejemplo, con hash), y debe haber validaciones para evitar accesos indebidos.
5. **RNF05 - Modularidad**
   El sistema debe estar diseñado de forma modular para permitir la incorporación de nuevos platos o funcionalidades sin grandes reestructuraciones.
6. **RNF06 - Mantenibilidad**
   El código debe estar documentado de forma clara para facilitar futuras modificaciones.
